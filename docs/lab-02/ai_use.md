## Reflection
This lab has given me the opportunity to work with AI tools more extensively and learn how to use them effectively in software development. I made sure to watch over it strictly to make sure it follows specifications and not run unnecessary commands. There were times where I had to pause and reject the AI agent's approach because it would try to run random codes unrelated to the task. So, whenever that happened I had to restructure my prompt to make it behave.
